# Data-Library-MiniProjects

This repository contains multiple Python projects demonstrating data analysis skills using Pandas, NumPy, and Matplotlib.
Each project focuses on real-world datasets and includes data processing, analysis, and visualization.

## Projects Included

1. **Student Marks Analysis** – Analyzes student marks, averages, and topper details.
2. **Temperature Analysis** – Evaluates daily temperature trends and identifies extreme values.
3. **Loan Eligibility Analysis** – Determines client eligibility based on income and credit score.
4. **Internet Performance Analysis** – Evaluates network speed, ping, and connection quality.
5. **Vehicle Efficiency Analysis** – Calculates vehicle mileage and analyzes fuel efficiency.
6. **Order and Return Analysis** – Analyzes revenue, return loss, and product return trends.
7. **Study Hours Analysis** – Examines the relationship between study time and academic performance.
8. **Sales Trend Analysis** – Analyzes product sales, revenue trends, and top-performing items.
9. **Sleep and Productivity Analysis** – Studies how sleep patterns affect productivity levels.
10. **Bus Transport Analysis** – Examines transport fees, route distribution, and student data.

## Tools & Libraries

* Python
